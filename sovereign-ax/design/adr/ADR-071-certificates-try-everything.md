# ADR-071 홈택스 증명서는 거절하지 않는다: 즉시발급 증명 전부를 스크립트로, 대화 도구 cert_draft

- 상태: 채택(대표 지시 2026-11-27)
- 바꾸는 것: cert-docs `hidden`(H-04 숨김), 대화 머리말의 "증명서 발급은 못 한다"

## 배경

대표 지시(2026-11-27): 세금계산서 발급이 되니 증명서 같은 문서 받기도 웬만한 곳은 된다. 앱이 "안 된다"고 거절하지 말고 일단 시도한다. 스크립트가 있으면 쓰고, 없으면 엔진 화면 에이전트(jev)로 이어 한다. 스크립트는 많이 준비해 둔다.

거절이 나던 곳은 넷이었다. (1) cert-docs가 납세증명서(H-04)를 숨겨 "떼지 못해요"로 답했다. (2) 목록 밖 증명서는 같은 문구였다. (3) 짧은 응대 머리말(chat_reply)이 "증명서 발급은 아직 못 한다"고 적었다. (4) 대화 에이전트(chat_agent)에 증명서 도구가 없어 모델이 cannot으로 답했다.

## 결정

1. 홈택스 「즉시발급 증명」 메뉴의 서류 전부를 민원증명 공통 템플릿(`scripts/playbooks/hometax-certificate.ts`)으로 만든다. 기존 4종에 16종을 더한다(`INSTANT_MORE`, 코드 H-30~H-45). 메뉴 이름과 주소(tm3lIdx)는 로그인 전 공개 전체메뉴에서 읽었다(2026-11-27).
2. 새 16종은 로그인 뒤 양식을 캡처하기 전이다. H-03·H-09와 같은 민원증명 공통 칸(사용용도, 제출처, 주민번호 공개, 수령방법, 발급수량)과 [작성완료] → 신청 확인 레이어 [신청하기]를 쓴다. 양식 제목을 모르니 제목 확인(s11t)은 빼고 머리말 민원명 되읽기(certDoc)로 서류를 맞춘다. 서류만의 칸은 선언하지 않는다(홈택스 기본값). 칸을 못 찾으면 엔진 화면 에이전트가 이어 하고, 비가역 단추는 지금처럼 승인 게이트 뒤에서만 누른다.
3. 납세증명서(H-04)를 숨기지 않는다. 개인사업자 로그인으로 막히면 패키지가 `portal.personal_login_required`로 멈추고 대표자 개인 인증서 안내를 낸다(기존 동작).
4. 대화 에이전트 도구 `cert_draft(doc, purpose)`: 사장님이 말한 서류 이름과 쓰임새를 그대로 넘기고, PC가 이름으로 스크립트를 골라 증명서 카드를 만든다. 맞는 스크립트가 없으면 `no_script`로 서류 이름을 되묻는다. 폰 도구 표에는 아직 넣지 않는다(폰에서 PC로 증명서를 맡기는 명령이 없다).
5. 빠른 단추와 첫 화면 목록은 그대로 둔다(`quick`): 모양을 바꾸지 않는다. 나머지 서류는 말하면 뗀다.
6. 홈택스 밖 서류(정부24 지방세 납세증명, 4대보험 완납증명 등)는 포털마다 로그인과 화면이 달라 이번에는 스크립트가 없다. 답은 "준비 중"이고, 범용 포털 실행(스크립트 없는 사이트를 에이전트로 처음부터 걷기)은 따로 설계한다.

## 영향

- 게시: 새 패키지 16개는 서명 의식(`services/registry/src/ceremony`)으로 레지스트리에 올려야 실행된다. 게시 전에는 받기에서 'unchanged'로 지나가고, 카드는 패키지 없음으로 멈춘다.
- 게이트웨이: 대화 도구 표가 게이트웨이에 있으므로 PC 앱과 같은 커밋으로 배포한다.
- 캡처할 것: `packages/engine/playbooks/CAPTURE-hometax-cert.md`의 "양식" 줄(서류마다 제목, 서류만의 칸, 제출 단추).
