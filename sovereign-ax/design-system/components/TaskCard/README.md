# TaskCard

대화 속에서 작업 하나를 처음부터 끝까지 보여 주는 카드다. 상태가 바뀌면 새 카드를 만들지 않고 이 카드가 바뀐다.

> v3.0(2026-11-24): 카드에는 어떤 상태에서도 테두리와 안쪽 선이 없다. 종류와 상태는 제목 앞 아이콘과 그 색으로 알리고, 단추는 중요한 것 먼저, PC는 줄 오른쪽에 붙이고, [중지]도 단추 줄에 둔다. 아래 글의 `is-turn`, `is-attention` 테두리와 머리 줄 [중지]는 지금 코드의 모습이고, 기준 캔버스 승인 뒤 코드와 함께 고친다. 기준은 `../../README.md` "v3.0 확정 기준".

- 구성(데이터 위계 순서): D2 제목 + StatusChip → D1 Amount → 안내 줄(필요할 때) → 버튼.
- 넘겨줄 것: 작업 이름과 거래처, 상태, D1 값과 분해, 안내 문장, 버튼 1~3개, 추정 값 개수.
- 상태별: 내 차례는 `sx-card is-turn`과 파랑 안내 줄(`sx-note`), 승인 대기(PC)는 "작성 완료" 한 줄로 접히고 값·[중지]·[승인하고 발급]은 main의 ApprovalCard에 있다(ADR-021 결정 7), 확인 중(응답이 끊겨 앱이 발급목록을 다시 조회)은 기본 테두리, 확인 필요(앱이 풀 수 없을 때만)는 `sx-card is-attention`과 `sx-note is-attention`.
- D3 목록은 카드에 넣지 않는다. 카드를 누르면 작업 패널에 KeyValue로 열린다.
- 초안 상태의 세금계산서 카드에는 [홈택스에서 준비] [부가세 포함하기] [금액 수정] [취소]를 둔다(ADR-020).
- 모양(v1.2): `surface` 바탕, `line` 1px, 모서리 12(`radius-lg`), 안쪽 16, 요소 사이 12. 내 차례·승인 대기는 테두리만 `accent`로 바뀐다. 결과 카드의 "어디로 무엇이 갔는지"는 접힘 영역(점진 공개)이며 머리 줄은 `ink-2` 글자와 꺾쇠, 펼치면 `line-soft` 선 아래 목록이다.
- 실행 중(v2.0, 구조 감사 H3): 준비 중·내 차례·발급 중·확인 중·확인 필요 카드는 머리 한 줄(`sx-run-hd`: 제목 · 지금 단계 `sx-card-now` · 칩 · 조용한 [중지])로 접는다. 사람 차례·확인 필요일 때만 할 일 한 줄(`sx-todo`)과 주요 단추 하나를 붙인다. 안내 상자(`sx-note`)를 카드 안에 두지 않는다. 확인 필요는 `is-attention` 안쪽 선이다. 금액·단계·값은 작업 패널에만 있다. 작성 중·완료·중지는 바꾸지 않았다.
- 하지 말 것: 왼쪽 색 띠, 그림자, 카드 안의 승인 버튼(PC, ADR-021).
- 수정세금계산서 카드(ADR-058 결정 5, 2026-11-24): 발급 카드와 같은 카드다. 위에서 아래로 원래 계산서 → 있었던 일 → 값 → 나가는 계산서 → 단추이고, 홈택스 수정발급의 세 단계(당초분 선택 → 사유 선택 → 작성)와 같은 순서다. 있었던 일은 두 묶음("처음부터 틀렸어요", "발급한 뒤에 달라졌어요") 여섯 줄의 답 후보이고 고르면 한 줄로 접힌다. 묶음은 홈택스 사유 화면의 두 묶음(작성일자가 당초와 같은 사유, 새 날짜를 쓰는 사유)을 쉬운 말로 옮긴 것이다. 잘못 적은 값은 그 자리에서 눌러 고치고 옛 값에 줄을 긋는다. 나가는 계산서 줄은 홈택스 [발급미리보기]를 대신해 실제로 나갈 장과 합계를 보인다. 음수는 − 부호만 쓰고 색을 바꾸지 않는다.
